Zero-Local-Build Deployment Manual
(Laravel Platform + Laravel-H5P package on Ubuntu 22 / Plesk / MySQL)
======================================================================

You asked for a branch you can download as zip, upload to Plesk, extract, and deploy without building locally.
This branch now includes that flow.

What you upload
---------------
Upload THIS branch zip to your domain `httpdocs`, then run one deployment script:

  ./scripts/auto_deploy_on_vps.sh

The script will:
1) create a full Laravel 12 app,
2) integrate this package as local source,
3) configure `.env` for MySQL,
4) run migrations and `h5p:install`,
5) optimize Laravel and publish the final platform into your domain root.


A) PLESK PREP
-------------
1. Plesk -> Websites & Domains -> your domain.
2. Hosting Settings -> ensure PHP is 8.2+.
3. In PHP settings, set:
   - memory_limit: 512M recommended
   - max_execution_time: 120+
   - upload_max_filesize/post_max_size: 64M+ for H5P


B) CREATE MYSQL DATABASE (PLESK + PHPMYADMIN)
----------------------------------------------
1. Plesk -> Databases -> Add Database.
2. Create a DB user with full privileges on that DB.
3. Open phpMyAdmin and verify login works.


C) UPLOAD + DEPLOY
------------------
1. Download this branch as zip from GitHub.
2. In Plesk File Manager, upload zip to `httpdocs`.
3. Extract zip in `httpdocs`.
4. Open Plesk Terminal (or SSH) at `httpdocs` and run:

   chmod +x scripts/auto_deploy_on_vps.sh
   ./scripts/auto_deploy_on_vps.sh

5. Provide prompts when asked:
   - MySQL DB name
   - MySQL username
   - MySQL password
   - App URL (`https://your-domain.com`)

6. After script completes, set Hosting Settings document root to:

   httpdocs/public


D) FINAL CHECKS
---------------
Run:

  php artisan about
  php artisan h5p:status

In browser verify:
- Home page loads
- H5P routes load
- H5P upload works
- `h5p_*` tables exist in MySQL


E) IMPORTANT NOTES
------------------
- This repository is a package (`composer type=library`), not a standalone app.
- The included script builds the full Laravel platform for you on the VPS automatically.
- No local machine build steps are required.


F) TROUBLESHOOTING
------------------
1. If deployment fails due Composer network access on VPS:
   - ensure outbound HTTPS is allowed from server to Packagist/GitHub.

2. If database fails:
   - validate credentials in phpMyAdmin,
   - rerun: `php artisan migrate --force`.

3. If permissions fail:
   - ensure web user can write `storage/` and `bootstrap/cache/`.
